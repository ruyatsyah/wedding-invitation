# Landing Page Assets Directory

Tempatkan semua foto, gambar, ikon, dan berkas aset lainnya untuk halaman landing di dalam folder ini.

Anda dapat mengakses aset yang diletakkan di sini secara langsung dari kode Next.js menggunakan jalur absolut:
`/assets/landing/<nama-file>`

Contoh:
Jika Anda menyimpan berkas `hero-bg.jpg` di folder ini, Anda dapat memanggilnya di komponen React seperti:
`<img src="/assets/landing/hero-bg.jpg" alt="Hero Background" />`
